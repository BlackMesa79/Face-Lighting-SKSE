Face Lighting SKSE
Player, dialogue NPC & follower lighting.

Adjustable face lighting for you, your companions and the people you talk to.


Add adjustable fill light to the player, your current dialogue partner, selected NPCs or recruited followers. Tune each lighting group separately, preview changes in-game, and keep the look that suits your setup.

Your lights. Your settings.

  • Player face light — Off initially, with automatic activation when entering dialogue enabled by default. An optional setting turns it off when dialogue ends. Visible in third person, with an optional first-person setting. Smooth player transitions default to 0.2 seconds; hides while sneaking by default.

  • Dialogue face light — Automatically lights the current dialogue partner in first or third person. Optional fade-in and fade-out, with adjustable duration.

  • Selected NPC face light — Aim at an NPC and press Shift+L to add and enable its light; press again to toggle. Crosshair and console targets can also be added from the menu. Individual enable/remove controls, with up to 32 NPCs per save.

  • Follower face light — Automatically lights recruited player teammates, with individual follower switches. Waiting teammates remain supported; dismissed followers leave the active list. Up to 32 loaded followers are lit, nearest first.

  • Dark-environment player light — Optional automatic switching based on local lighting, with separate thresholds and a sustained-condition delay. Choose fixed compensation or live exclusion of this mod's player and NPC light contributions. Live exclusion requires the verified Skyrim 1.6.1170 code layout; see Compatibility below.

  • Independent controls — Adjust intensity, position, and color temperature from 2000–10000 K. Adjust radius in regular mode. CS inverse-square mode offers Automatic range (default) or Manual radius, independently of intensity.

  • Bone orientation — Optional head-bone rotation following, independently configurable for player, dialogue, selected NPC and follower lights.

  • Live configuration — Three redesigned pages: General, Player face light, and NPC face light, with individual NPC controls and optional roster success/failure notifications. English and Simplified Chinese, with automatic Windows UI language detection and support for additional language files.



Each NPC uses one managed face light. Dialogue settings take priority, followed by selected NPC settings, then follower settings.

Automatic dark-environment control is off by default and requires the player light master switch. Defaults are below 30 to turn on and above 50 to turn off, sustained for 2 seconds. Transitions and a settling period suspend decisions. Readings are not percentages and do not follow a fixed day/night schedule. Live exclusion needs no manual contribution calibration; fixed compensation does, and it does not remove nearby NPC light contributions.

Keyboard & controller
Toggle player lighting with L, or choose your own shortcut with an optional Shift, Ctrl, or Alt modifier. F1–F12, number keys, navigation keys and numpad keys are also supported.

Aim at an NPC and press Shift+L to add/toggle selected NPC lighting. Its binding is configurable and takes priority if it matches the player shortcut.

Gamepad bindings are independent and disabled by default. Choose a button and an optional modifier on the Player page — for example, hold LB and press D-pad Up. Buttons use Xbox-style labels, including LT/RT. Save your binding before closing the menu.

Shortcuts do not block the buttons' original game actions. Steam Input mapped to keyboard keys uses the keyboard shortcut instead.

Get started
Install with your mod manager and launch through SKSE. No ESP or Papyrus scripts are included.

Required
SKSE64 and Address Library, matching your game version.

For the in-game menu
SKSE Menu Framework. You can also edit Data/SKSE/Plugins/FaceLighting.ini and restart.

Open FaceLighting in the framework. Changes preview immediately and remain while switching pages. Save all settings keeps them; closing the menu discards unsaved edits. Keep your existing INI when upgrading; Mod Organizer users should also check the overwrite folder. New options use defaults when absent.

NPC list edits and individual follower switches apply immediately and persist when you save the game. The menu save button only saves configuration. Preserve the matching .skse co-save when moving saves.

First-person lighting, automatic dark control and diagnostics are off by default. Player lighting starts off with dialogue activation enabled; dialogue, selected and follower groups are enabled. To use live exclusion, save that mode and restart the game on first activation. Detailed diagnostic logging is optional.

Community Shaders
CS is optional. Inverse-square falloff uses automatic linear-light flags and calibrated intensity. Use the Enable Community Shaders integration switch in General. When enabled, integration works with a loaded CS DLL without a version whitelist; turn it off for regular lighting. The detected DLL and ISL version information stays visible for troubleshooting. Regular lighting remains available without CS.

One setup step: in General, match “My CS global Linear Lighting is enabled” to your actual CS setting. This selects the face lights' color handling; it does not turn on CS. Update it whenever you change the global CS option.

Compatibility
Core lighting has previously passed in-game testing on Skyrim 1.5.97; the new features were tested on 1.6.1170. Do not assume every new feature has been retested on every runtime. The plugin is built for SE/AE; use dependencies matching your runtime. VR is not supported. Skyrim 1.7.x support is planned and is not included in the current release.

Live exclusion is limited to the verified Skyrim 1.6.1170 calculation layout. It is unavailable on 1.5.97, and changes from other plugins can prevent validation. Missing, stale or invalid readings pause decisions; the mode does not silently fall back to fixed compensation. Exclusion changes only this mod's automatic decision input, preserving the game's original lighting and stealth values. Manual lighting and the separate fixed-compensation mode remain available.

Custom followers need Skyrim's player-teammate flag for automatic recognition. Ashe – Crystal Heart was recognized in user testing; other custom followers are not individually certified. Use the selected NPC list when automatic recognition is unavailable.

Direct CS testing covers Jiaye build 0516. Users have reported successful use with other versions, but those builds have not been individually verified. ENB is not yet validated.

Face lights can affect sneak detection. By default, player sneaking immediately hides both player and teammate face lights, including selected or dialogue lighting on those teammates. This takes priority over automatic darkness control. Standing restores eligible lights without changing roster switches. Non-teammate NPC lights remain independent and may still contribute to detection.

Lights are shadowless point lights, not skin-only lighting, and can also illuminate nearby objects. Actors need a standard head node. Dialogue detection uses Skyrim's standard dialogue menu and speaker; replacement dialogue systems may need separate support. Automatic lighting of all nearby NPCs is not included.

Death-state, missing-head and model-change safeguards clean up invalid lights. Player decapitation could not be reproduced during testing and remains unverified; these guards are not a guarantee against every engine or mod-related death crash.

Translations
Includes English and Simplified Chinese. To create a translation, copy SKSE/Plugins/FaceLighting/Languages/en.ini to a language code such as fr.ini. Save as UTF-8, set Name under [Language], and translate only the values under [Strings], keeping keys unchanged.

Restart the game, select your language in General, and save. Missing text falls back to English; sidebar names update after restarting. Your menu font must support the language.

Share only your language file with its folder structure. No recompilation required. Full instructions: Translation guide on GitHub.

Feedback & credits
When reporting an issue, include your game/SKSE version, CS build if used, reproduction steps, and FaceLighting.log. Diagnostic controls are not shown in the release menu. If requested for troubleshooting, set DebugLogging=1, LightDiagnostics=1 or ExclusionDiagnostics=1 in the INI and restart; return them to 0 afterwards. Add a crash log for crashes.
