FACE LIGHTING
Player & dialogue NPC lighting.

Adjustable face lighting for you and the people you talk to.


Add a gentle fill light to the player's face or your current dialogue partner. Tune each light separately, preview changes in-game, and keep the look that suits your setup.

Two lights. Your settings.

  • Player face light — Off initially, with automatic activation when entering dialogue enabled by default. An optional setting turns it off when dialogue ends. Visible in third person; hides while sneaking by default.

  • Dialogue face light — Automatically lights the current dialogue partner in first or third person. Optional fade-in and fade-out, with adjustable duration.

  • Independent controls — Adjust intensity, position, and color temperature from 2000–10000 K. Adjust radius in regular mode. CS inverse-square mode offers Automatic range (default) or Manual radius, independently of intensity.

  • Bone orientation — Optional head-bone rotation following, independently configurable for player and dialogue NPC lights.

  • Live configuration — Three pages: General, Player face light, and NPC face light. English and Simplified Chinese, with automatic Windows UI language detection and support for additional language files.



Keyboard & controller
Toggle player lighting with L, or choose your own shortcut with an optional Shift, Ctrl, or Alt modifier. F1–F12, number keys, navigation keys and numpad keys are also supported.

Gamepad bindings are independent and disabled by default. Choose a button and an optional modifier on the Player page — for example, hold LB and press D-pad Up. Buttons use Xbox-style labels, including LT/RT. Save your binding before closing the menu.

Shortcuts do not block the buttons' original game actions. Steam Input mapped to keyboard keys uses the keyboard shortcut instead.

Get started
Install with your mod manager and launch through SKSE. No ESP or Papyrus scripts are included.

Required
SKSE64 and Address Library, matching your game version.

For the in-game menu
SKSE Menu Framework. You can also edit Data/SKSE/Plugins/FaceLighting.ini and restart.

Open FaceLighting in the framework. Changes preview immediately and remain while switching pages. Save all settings keeps them; closing the menu discards unsaved edits. Keep your existing INI when upgrading.

Community Shaders
CS is optional. Inverse-square falloff uses automatic linear-light flags and calibrated intensity. Choose Automatic, Manual enable, or Disabled integration in General. Manual enable lets unrecognized builds use the integration while still requiring CS to be loaded. Regular lighting remains available without CS.

One setup step: in General, match “My CS global Linear Lighting is enabled” to your actual CS setting. This selects the face lights' color handling; it does not turn on CS. Update it whenever you change the global CS option.

Compatibility
Skyrim 1.5.97 has passed in-game testing. The plugin is built for SE/AE; use dependencies matching your runtime. VR is not supported. Skyrim 1.7.x support is planned and is not included in the current release.

Jiaye builds 0516 and 0816 have passed user testing; 0816 used Manual enable. Other experimental builds may differ. ENB is not yet validated.

Face lights can affect sneak detection. By default, sneaking temporarily hides the player light without changing its enabled setting. Dialogue lighting is unaffected by this option and may still contribute to detection.

Lights are shadowless and can also illuminate nearby objects. Actors need a standard head node. Dialogue detection uses Skyrim's standard dialogue menu and speaker; replacement dialogue systems may need separate support. Persistent lighting for manually selected NPCs is not included in this release.

Translations
Includes English and Simplified Chinese. To create a translation, copy SKSE/Plugins/FaceLighting/Languages/en.ini to a language code such as fr.ini. Save as UTF-8, set Name under [Language], and translate only the values under [Strings], keeping keys unchanged.

Restart the game, select your language in General, and save. Missing text falls back to English; sidebar names update after restarting. Your menu font must support the language.

Share only your language file with its folder structure. No recompilation required. Full instructions: docs/LOCALIZATION.md in the download.
