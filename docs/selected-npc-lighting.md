# 指定 NPC 面光（开发构建）

本模块与随从面光、全新配置菜单一起纳入 **0.9** 发布目标；范围内 NPC 自动添加面光、Skyrim 1.7.x 支持及其他剩余内容延后。完整范围见 [NPC 面光发布计划](NPC-face-light-plan.md)。本说明记录当前指定 NPC 模块的实现与验收状态，不表示 0.9 已完成或发布。

入口：面部光照 → NPC 面光 → 指定 NPC。

## 使用

1. 游戏中用准星对准普通 NPC，按 **Shift+L**，即可加入名单并开启面光；再次对准同一 NPC 按下则切换其个人面光，关闭后仍保留在名单。对已识别随从则直接切换随从偏好，不额外加入指定名单。已有指定记录与随从偏好同步更新，对话来源独立。没有有效 NPC 时不操作，不会使用旧目标或控制台目标。可在“指定 NPC”页修改主键和 Shift/Ctrl/Alt 修饰键，保存所有设置后生效；设为 Off 可禁用。与玩家绑定相同时 NPC 快捷键优先。原有菜单添加准星／控制台目标入口仍可用。
2. 名单支持逐人启停和移除，最多 32 名。名单操作立即生效，保存游戏时写入该存档的 SKSE `.skse` 配套文件；“保存所有设置”只保存光照参数，不代替游戏存档。
3. 指定 NPC 共用一组独立光照参数，支持强度、色温、范围、位置、骨骼朝向、CS 适配及过渡。参数仍使用预览／保存／撤销流程；关闭菜单撤销未保存参数，但不撤销名单操作。
4. 同一个 NPC 对话期间使用对话面光参数，结束后恢复指定 NPC 参数，不叠加第二盏灯。关闭“对话面光”不会关闭其常驻指定面光；名单禁用也不会禁止独立的对话面光。

快捷键开启面光时若对应总开关已关闭，会开启并保存该组：随从使用随从组，普通 NPC 使用指定组，组内其他已启用角色也恢复面光。关闭操作不会开启任何组。菜单个人开关只改偏好，不自动开启总开关。强度为 0 时不会产生可见光照。菜单、暂停、控制台、文本输入和游戏失去焦点时不响应快捷键。名单满员时不能新增普通 NPC，但仍可切换已有 NPC 和随从。

“移除”只删除指定名单记录，不禁用自动随从来源；如需关闭随从，请使用个人开关。个人偏好随游戏存档保存。统一逻辑和测试清单见 [个人面光开关](personal-light-switches.md)。

名单按存档隔离，新游戏与没有本模组记录的旧存档从空名单开始。复制存档时保留对应 `.skse` 文件。参数仍保存在全局 FaceLighting.ini 的 Selected* 键中，不是每名 NPC 的独立参数。

## 生命周期与边界

- 持久化参考对象 FormID，读取使用 SKSE ResolveFormID 适配加载顺序；不保存裸指针、ActorHandle 或光源场景对象。无法解析的记录跳过；可以解析但暂未加载的 NPC 保留在名单。
- 排除玩家、已删除、禁用和死亡目标。仅对已有 3D 且 cell 已附加的目标提交请求，不强制加载角色、不扫描附近人群。
- 离开场景清理光源，目标重新加载后恢复。缺少标准头骨的形态不能显示面光。
- 名单修改排入游戏主线程；UI 读取加锁快照。读档重置会使旧队列任务失效。
- NPC 管理容量 34：32 名常驻目标加对话余量；对话最多保留一个无请求的淡出目标。仍有指定请求的 NPC 不因对话切换而被清理。
- 光源仍是原生点光源，会影响附近物体和潜行侦测。玩家的潜行隐藏开关不控制 NPC 面光。

## 菜单样式

参考并阅读了以下项目的布局实现，未复制其模板或素材：

- [Cinematic Idle Camera — menu.cpp](https://github.com/The-Evil-Fox/CinematicIdleCamera/blob/master/src/menu.cpp)：分组卡片、标题和列表操作区。
- [Cinematic Conversation Camera — Settings.cpp](https://github.com/fatalCMD/ccc/blob/main/src/Menu/Settings.cpp)：局部强调色、页面标题、折叠分组与紧凑排版。

本项目采用暖金强调色、圆角控件和折叠区，保留三个侧栏入口；所有样式压栈后在本页结束时恢复，避免影响其他模组。中英文已更新；自定义翻译缺少新键时回退英文。新增 API 在注册前检查导出，缺失时记录日志并跳过菜单注册。

## 验证

编译及八项自动测试通过（包括 SE/AE 角色死亡检查的虚函数分派回归测试）。自动测试覆盖设置保存／归一化、NPC 请求合并与容量、存档记录大小／重复／错误标志／缺失插件／ID 重映射，以及原有位置、CS、本地化和玩家对话行为。实际 SKSE 存读档回调和游戏内菜单未在自动测试中执行。

游戏验收：

- Shift+L 首次添加并开启、重复按下启停、无目标／无效目标无操作、满员时已有目标仍可切换；自定义快捷键、关闭快捷键及与玩家快捷键冲突。
- 准星与控制台分别添加、重复添加、逐人启停、移除，确认显示目标正确。
- 保存游戏 → 退出重进 → 读档，名单和逐人开关恢复；换另一个旧存档或开新游戏时不串名单。
- 离开并返回场景、目标卸载／死亡，确认没有残留光源。
- 与名单内 NPC 对话，检查参数优先级及结束恢复，尤其逆平方／普通模式和不同位置之间切换。
- 中英文菜单分组、窄窗口、缩放、参数预览和撤销；打开其他模组菜单时配色不受影响。

版本号仍为开发用 0.8.2；不修改已发布的 0.8.2 压缩包，不升级 CommonLib，不宣称新增 1.7.x 支持。

2026-09-19 用户确认修复后的功能及跨人物／同人物不同时间点存档测试通过。随后随从模块接入，总光源管理容量扩展为 66；指定 NPC 名单仍限 32 名。详见 [随从面光说明](follower-lighting.md)。

新增名单操作反馈：快捷键未选中有效 NPC、菜单无有效目标、名单已满、重复添加及添加成功均有通知；快捷键重复切换显示启用／禁用。无有效目标的菜单按钮允许点击以显示失败原因。结果也显示在名单页并写入日志；成功加入名单不保证零强度或关闭总开关时可见。
