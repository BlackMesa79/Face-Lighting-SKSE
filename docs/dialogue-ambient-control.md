# 对话面光的环境亮度控制

开发日期：2026-10-04。当前为本地开发构建，默认关闭。此前的玩家自动控制保持独立；随从和指定 NPC 没有新增环境自动开关。

菜单位置：玩家自动控制位于“玩家面光 → 玩家面光自动控制”；玩家/对话共用的检测频率位于“基本”；对话自动控制位于“NPC 面光 → 对话面光”。菜单提示已简化，本文件保留详细说明。

## 开启与设置

进入 **NPC 面光 → 对话面光 → 启用与显示**，设置“对话面光环境控制模式”：

- 关闭：沿用既有对话面光行为。
- 自动对话面光（固定补偿，旧方案）：使用玩家受光缓存，扣除已存在的玩家灯和对话灯实测贡献，需校准。
- 自动对话面光（实时排除面光）：复用已验证的玩家实时排除采样，扣除本模组所有玩家/NPC 灯的贡献，不使用补偿数值。第一次启用需保存并重启游戏，只限已核验的 Skyrim 1.6.1170 代码布局；不支持的版本或被其他插件改写的采样路径不会自动退回固定补偿。

通用设置新增“环境检测频率”下拉框，玩家与对话自动控制共用：性能优先每 1 秒、均衡每 0.5 秒、响应优先每 0.2 秒，默认性能优先。只节流读取亮度与判断阈值；过渡、安全清理、暂停/说话者/cell 检查仍沿用每帧处理。正常轮询间隔不会被当成暂停，较长断档重新累计持续条件；卡顿后不补执行积压检查。INI 为 General/AmbientPollMode=0（1 均衡、2 响应优先）。

对话有独立的阈值和持续时间，默认 **低于 30 开灯、高于 50 关灯、持续 2 秒**。两阈值之间维持原决定，避免反复闪烁。新对话/新说话者/换 cell/变更控制参数从关闭开始，待持续暗处确认后开启；明亮场景不会先短暂开灯。物理灯开关变化和固定补偿淡入淡出会等待缓存稳定，实际等待可能长于设定持续时间。

玩家自动控制模式可以关闭，玩家主开关也可以关闭，对话自动控制仍能独立使用。原有“进入对话时开启玩家面光”设置继续按自己的规则工作，不受对话灯的环境判断控制。

## 采样位置与限制

**采样来自玩家位置，不是对话 NPC 头部或皮肤的直接受光。** 玩家处明亮通常适合作为关闭对话灯的依据；玩家站在阴影中而 NPC 被阳光直射时，两者读数可能不同。因此不能承诺逐角色的日照判断。这一版不扩展未经核验的引擎采样 hook。

实时排除可去掉本模组的灯光反馈。固定补偿只是一种估算：玩家补偿值与玩家自动控制共用；对话补偿值是对话灯在玩家采样处造成的 raw 差值，随距离、范围、位置和强度变化，并不是光照强度滑块本身。NPC 与玩家相对距离改变后可能需重新校准。模组没有要求玩家移动，原地收到新亮度也能触发控制。raw 来自引擎缓存，实时排除只是旁路记录引擎已完成的亮度查询；它们并非主动采样。静止时若引擎没有更新，反复读取旧缓存不会检测到新环境，实时排除的旧样本超过一秒后还会被拒绝。降低轮询间隔不能修复这个来源问题。目前未强制引擎重算，未将旧采样无限延长有效期。

raw 缓存的刷新时机仍不明确；实时排除继续使用原有同次校验/同 cell/一秒有效期。

缺失、过期或非有限读数不会被当作黑暗，正在运行的决定保持不变且打断待定计时；新对话若没有有效暗处读数会保持关闭。暂停、配置预览和控制台不累计持续时间。跨 cell、换说话者或重新读档不继承旧场景的开灯决定。

## 来源、过渡与保存

- 对话总开关、强度、死亡/骨骼检查及队友潜行隐藏继续优先。
- 环境变化触发的开关沿用对话面光过渡参数；亮处关灯可让当前对话来源完成淡出，其余角色仍立即暂停。
- 对话对象即使属于随从/指定名单，环境拒绝对话灯时也不从个人来源重新开灯。对话结束恢复原名单偏好与同时亮灯预算，不修改存档偏好。
- 新选项随配置预览、保存、撤销和恢复默认值操作；升级缺键默认关闭。部署和发布安装包都不覆盖/包含初始用户配置 INI。
- 公共 API V1 布局不变，对话对象被环境抑制时返回 HiddenAmbient，淡出中可同时返回 Registered/Fading。

INI 的 General 节使用：

```ini
DialogueAmbientMode=0
DialogueAmbientCompensation=80
DialogueAmbientOnThreshold=30
DialogueAmbientOffThreshold=50
DialogueAmbientDelay=2
```

模式值为 0 关闭、2 固定补偿、3 实时排除。整数/浮点读取和归一化会拒绝非法值，保证阈值顺序和持续时间范围；不会更改旧玩家控制模式。

## 验证与游戏测试

自动测试额外覆盖 1/0.5/0.2 秒三档共享调度、频率切换、无积压执行、暂停复位和提供新读数时不需移动也能触发。自动测试覆盖亮处首次对话不闪灯、持续暗处启用、短暂波动、滞回、采样不可用、暂停/长间隔、跨 cell/说话者/参数复位、固定补偿反馈、实时排除不重复扣除、对话淡出与个人来源隔离，以及结束恢复预算。设置测试覆盖保存重载、旧配置默认值、玩家关闭时独立启用、非法值、预览和保存失败。实际游戏内表现仍需用户验证。

建议在 1.6.1170 使用实时排除测试：室外明亮/阳光处开始对话、暗酒馆开始对话、对话中靠近或远离火把、与已登记随从对话并关闭/恢复，检查其他 NPC 是否继续暂停和结束后恢复。玩家灯与玩家自动控制分别关闭时也各测一次，验证对话设置独立。固定补偿及 1.5.97 仍需单独实测，不依据 AE 结果宣称已验证。
