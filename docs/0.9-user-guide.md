# Face Lighting SKSE 0.9

## Quick start

Install with a mod manager and launch via the matching SKSE64. Address Library is required. Install SKSE Menu Framework for the settings menu. Community Shaders is optional. No ESP or Papyrus scripts.

- L: toggle player light. Shift+L: aim at an NPC, add and enable; repeat to toggle.
- General / Player face light / NPC face light: preview parameters and save all settings.
- Selected lists and follower switches: changes are immediate; save the game to persist them in its SKSE co-save.
- Followers: recognized by player-teammate state, with individual switches. Use selected NPC lighting for unrecognized custom followers.
- Sneak hiding: immediately hides player and teammate lights, including selected/dialogue sources on teammates. Other NPCs are independent.
- Automatic darkness control: enable the player master switch, choose a mode in General, save and close the menu. Live exclusion requires the verified 1.6.1170 layout and a restart after first activation. Detailed logging is optional. Fixed compensation is a separate, manually calibrated alternative.
- Defaults: automatic control, first person and diagnostics off; player initially off with dialogue activation enabled; follower/selected/dialogue groups and sneak hiding on. Player transitions are 0.2 seconds.
- Thresholds: below 30 on / above 50 off for 2 seconds, with transition settling. Readings are not percentages or time-of-day rules. Missing/stale samples pause decisions.

## Upgrade and limits

Preserve existing INI files, including Mod Organizer overwrite settings, and matching .skse co-saves. New missing keys use defaults. Runtime validation for live exclusion can fail if another plugin changes the checked calculation code. No VR or Skyrim 1.7.x support; ENB is unverified. Core lighting has prior 1.5.97 testing; the 0.9 feature tests used 1.6.1170.

Lights are native shadowless point lights: they affect nearby objects and may affect detection. Live exclusion only affects this mod's automatic decisions, not the engine's original lighting or stealth calculations. Standard head nodes are required. Invalid/dead actors and missing/replaced models are cleaned up. Player decapitation was not reproduced and remains unverified.

## 中文使用说明

L 切换玩家面光；准星对准 NPC 按 Shift+L 添加并开灯，再按切换。菜单参数用“保存所有设置”保存；指定名单和随从逐人开关需保存游戏，保留对应 .skse 文件。

随从自动识别依赖队友标记，未识别的独立随从可以手动添加。潜行隐藏会立即隐藏玩家及队友所有来源的面光，站起后按当前条件恢复，不修改名单开关。

暗环境功能默认关闭。打开玩家总开关，再选自动模式。实时排除无需手调补偿，但仅支持已核验的 1.6.1170 布局，首次启用保存后重启。旧固定补偿方案仍保留。阈值默认低于 30 开、高于 50 关，持续 2 秒；数值不是百分比，也不按早晚时间强制开关。无有效采样时暂停判断。

升级保留原 INI，MO 用户注意 overwrite 中的配置。发布包不含个人测试数据。VR、1.7.x 及全范围 NPC 自动照明不在本版支持范围；玩家斩首仍未实测确认。


CS integration uses a single on/off switch and requires a loaded CommunityShaders.dll; no version whitelist is used. Legacy CSMode=0 (automatic) and 1 (manual) migrate to enabled (1); 2 stays disabled. DLL and ISL version information remains visible. Direct CS testing covers Jiaye build 0516; other builds have user reports, not individual certification. Release menus omit diagnostic checkboxes, sample dumps, MARK buttons and observation-only ambient mode. INI diagnostic keys remain available for requested troubleshooting; ordinary automatic control does not emit per-second diagnostic dumps.

CS 适配改为开关，不再按版本限制；旧自动和手动开启迁移为开启，旧关闭保持关闭。界面保留 DLL/ISL 版本信息。正式菜单移除调试数据、记录和标记按钮，仅在需要排查时手动通过 INI 启用诊断。关闭诊断不影响实时排除自动开灯。
