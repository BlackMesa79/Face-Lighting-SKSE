# 受光数值诊断测试

本文说明原始受光诊断；暗环境控制模式关闭时只记录玩家受光缓存值，不自动开关灯、不排除自身或 NPC 面光。2026-09-20 新增的补偿与自动控制实验请参见 [补偿测试说明](ambient-compensation-testing.md)。

## 开启与查看

1. 重启游戏后，在“通用”页开启“记录玩家受光数值（诊断）”，点击“保存所有设置”，关闭菜单。
2. 游戏正常运行时每秒采样一次。配置菜单、控制台及暂停期间不采样；加载和读档结束后开启新的采样段。
3. 重新打开通用页可看最近一次游戏中采样。`raw` 是原始受光值，不是百分比，缓存刷新时间未知。`unavailable` 表示没有可用高处理级数据或数值不是有限数，不能当作黑暗。
4. “在日志中标记最近采样”会写入 MARK 和该次读数，方便按测试顺序定位。它不会在菜单里强制测量。
5. 记录写入 `Documents/My Games/Skyrim Special Edition/SKSE/FaceLighting.log`，搜索 `[LightProbe]`。用户当前文档目录对应 `D:/MyFiles/Documents/My Games/Skyrim Special Edition/SKSE/FaceLighting.log`。测试完保留本轮日志，再重新启动游戏，以免后续启动覆盖日志。
6. 测试结束可关闭诊断并保存，默认不开启，不需要打开 Debug Logging。

## 推荐测试顺序

先固定天气、时刻、曝光预设、地点和镜头，使用第三人称，避免对话自动开关影响手动对照。每组保持约 10 秒。

1. 暗处：关闭玩家、对话、指定、随从四类面光，观察基础值。
2. 同地点：只开启玩家面光，再关闭，比较是否随自身补光明显变化。
3. 同地点：保持玩家灯关闭，只开启附近随从／指定 NPC 灯，再关闭，比较互相补光贡献。
4. 所有面光关闭：从阴影走到明亮区域，进入／离开建筑，再比较火把旁与暗角。
5. 对比站立与潜行、第一与第三人称。若数字长期不变，也保留日志，不手动把数值解释成环境不变。
6. 需要比较其他 CS／曝光预设时另记一组，并说明预设；诊断不会自行读取或改动其所有外部设置。

提供测试顺序和对应场景说明即可，不需要先挑选自动开关阈值。

## 字段说明

- `sample`：当前采样段编号；`t`：本段经过秒数；日志前缀含系统时间。
- `raw`：HighProcessData.lightLevel 的原始缓存值。源码编译时检查成员偏移；仍需游戏数值验证，不代表已经校准。
- `cell`、`interior`、`pos`：玩家区域与坐标。
- `firstPerson`、`sneaking`：当前人称与潜行状态。
- `playerEnabled`：玩家参数中的开关；`playerLight`：实际是否持有已注册的玩家光源；`playerIntensity`：配置强度。
- `npcEntries`：NPC 管理条目数量，包含淡出中或尚未成功创建光源的条目，并非精确可见灯数。
- `dialogue`、`selected`、`follower`：三类 NPC 光源总开关。
- 随后的 `config sample=...` 行补充第一人称／潜行选项、CS 是否实际采用、玩家逆平方及全局线性设置，以及三类 NPC 配置强度。

本轮没有模拟游戏中的受光数据；自动测试只覆盖设置持久化与周边功能。真实取值、刷新行为和自身灯的影响必须由本轮游戏测试确认。
