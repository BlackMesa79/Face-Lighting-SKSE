# 暗环境补偿实验版（2026-09-20）

仅控制玩家面光，默认关闭，保留既有 NPC／随从逻辑。用户纠正上一轮场景对应：白天现场读数为八十多，不能将日志中的 24.9 标记认定为白天。暗处关灯约 22，开灯可超过 100；固定差值补偿是否跨场景稳定仍需本轮验证。

## 设置与测试

通用页 → 暗环境玩家面光（实验）。先选择“仅观察补偿值”，保存全部并关闭菜单。玩家页总开关控制手动开灯；此模式不自动切换。实验模式启用时自动每秒写入 FaceLighting.log，不必另开诊断开关。菜单展示最新游戏采样，打开菜单期间停止判定。

先关闭对话、指定 NPC、随从面光（其光照不会被扣除），在同一位置、相同视角分别记录开灯和关灯稳定数值，差值填写到“面光补偿值”。暗处、亮处各做一次，最好往返重复；等待数值稳定后使用“标记最近采样”。补偿是当前整套光源设置对应的 raw 差值，不是 Intensity，也不按 Intensity 自动缩放。调整强度、范围、偏移、头部跟随、CS 设置或人称后需要重新核对。

初始补偿 80，开灯阈值 30，关灯阈值 50，条件持续 2 秒；这些都是可调试验值。关灯时 estimated = raw；玩家光源存在时 estimated = max(0, raw - compensation)。负值被截断为零，过大的补偿可能掩盖亮处，应同时查看 raw。

校准后选择“自动控制玩家面光”，开启玩家面光总开关，保存并关闭菜单。暗处低于 30 持续 2 秒开灯；亮处高于 50 持续 2 秒关灯；中间区间维持原状态。启动／设置改变／换场景或人称／实际灯光状态变化后另有 2 秒稳定期，因此初次通常需要约 4 秒。无效读数保留决定并中断计时；暂停或长帧间隔后重新稳定。缓存是否真正刷新仍不能由此保证。

自动决定不写回 Enabled 或 INI。总开关关闭优先、潜行隐藏和第一人称许可仍生效；对话原有逻辑可能修改总开关，但也不绕过自动判定。关闭实验模式即恢复原有手动行为。只使用一个玩家补偿值，不为随从或第一人称单独校准。

日志保留 `[LightProbe]` 和 MARK，新增 ambientMode（0 关闭／1 观察／2 自动）、compensation（本次实际扣除量）、estimated、autoOn（控制器决定）、eligible、settling、low/high/delay。样本在本帧改灯之前读取，playerLight 是采样时已存在的光源；autoOn 可代表接下来执行的状态。NPC 管理条目数不是实际发光数量。`[Ambient]` 记录自动状态切换。

重点反馈：暗处开灯后是否保持；走到亮处／火把旁是否关灯；往返是否正常；有无周期性闪烁；开关面光前后 estimated 是否接近。随后再启用随从，观察靠近是否干扰。不能将本次算法测试等同于真实引擎缓存和全部场景已经验证。
